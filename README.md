# 保龄球高手

在浏览器里打一局保龄球。瞄准线会左右扫过，按下锁定方向，再等力度条走进中间的色带出球。太轻到不了瓶，太重会直穿过去。同样的手法也不会每次都得到完全一样的结果。计分和球场一样。

在这里玩：https://yixin-zhu.github.io/yx-bowling-game/

## 怎么打

- 空格、点击球道，或按按钮，都可以锁定方向和出球。
- 力度条上的浅色带是合适的力度。锁定之后，指示标会停在你选定的位置。
- **再来一局** 清空计分，重新摆上十个瓶子。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

然后打开 http://localhost:5173/

| 命令 | 作用 |
| --- | --- |
| `npm test` | 检查计分，以及力度、方向和出手误差 |
| `npm run build` | 做类型检查，并把静态页面写到 `dist/` |
| `npm run preview` | 打开构建好的页面 |

推送到 `main` 会跑测试，并用 GitHub Pages 发布。
